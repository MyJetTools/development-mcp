The twin of the Dioxus client's `Cargo.toml`, `Dioxus.toml` and `build.rs`. Versions as of
2026-10-16; each is pinned on purpose and moved on purpose.

## analysis_options.yaml — the zero-warnings policy

The twin of `#![deny(warnings)]` + `#![deny(clippy::pedantic)]`: `very_good_analysis` is the strict
set, and the analyzer's strict modes are on.

```yaml
include: package:very_good_analysis/analysis_options.yaml

analyzer:
  language:
    strict-casts: true
    strict-inference: true
    strict-raw-types: true
  exclude:
    - lib/bridge/**            # generated by flutter_rust_bridge
    - "**/*.freezed.dart"      # generated for the bridge's enums with data
    - lib/theme/tokens.g.dart  # generated from the CSS tokens

linter:
  rules:
    public_member_api_docs: false   # an app, not a published package
```

- `flutter analyze --fatal-infos --fatal-warnings` MUST pass, and
  `dart format --output=none --set-exit-if-changed .` leaves nothing to change.
- **NEVER** `// ignore:` as a solution — the `#[allow(clippy::…)]` rule. Fix the cause.

## rust/Cargo.toml

```toml
[package]
name = "client_bridge"
version = "0.1.0"
edition = "2024"

[lib]
crate-type = ["staticlib", "cdylib"]

[dependencies]
flutter_rust_bridge = "=2.13.0"
# the pure core — no `web`: no FlUrl, no tokio, no TLS in the phone's library
client-common = { path = "../../client-common", features = ["chart"] }
rest-api-shared = { path = "../../rest-api-shared" }

[profile.release]
# NOT the web bundle's `panic = "abort"`: across the bridge an unwinding panic becomes a
# Dart PanicException; an aborting one kills the app with no word about why
panic = "unwind"
opt-level = 3
lto = true
codegen-units = 1
```

## The guard files

`test/` holds what `build.rs` enforces in a Dioxus client — each a plain `flutter test`:

| File | Fails when |
|---|---|
| `test/routes_guard_test.dart` | a route the core's vocabulary does not have, or a vocabulary path the app does not declare (topic `routing`) |
| `test/tokens_are_current_test.dart` | the CSS tokens changed and `tokens.g.dart` was not regenerated |
| `test/chart_label_width_test.dart` | the label font no longer matches the character width the chart engine assumes (`get_flutter_design_patterns`, topic `canvas`) |
